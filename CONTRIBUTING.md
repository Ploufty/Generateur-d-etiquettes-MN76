# Contribuer à Etiq classe

Merci de votre intérêt ! Toutes les contributions sont les bienvenues, même petites.

## Signaler un problème ou proposer une idée

Ouvrez un **ticket** (menu *Tickets* du projet sur la Forge) en précisant :
- ce que vous avez fait, ce que vous attendiez, ce qui s'est passé ;
- le navigateur et l'appareil (PC, TNI, VPI, tablette) ;
- si possible une capture d'écran ou le fichier `.etiq` concerné (sans photo ni nom d'élève).

## Proposer une modification

1. Créez une copie du projet (*fork*) ou une branche.
2. Faites vos modifications. Le projet n'a besoin d'aucun outil : ouvrez `index.html` dans un navigateur pour tester.
3. Vérifiez à la souris **et** au tactile si possible, en mode clair et sombre.
4. Ouvrez une **demande de fusion** (*merge request*) en expliquant le changement.

## Règles

- Code sous licence MIT, contenus sous CC BY 4.0 : en contribuant, vous acceptez de publier votre apport sous ces licences.
- N'ajoutez que des ressources (images, polices, sons) sous licence libre compatible, avec leur attribution dans le README.
- Aucune donnée personnelle ni secret dans le dépôt.
